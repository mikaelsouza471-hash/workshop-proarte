# Workshop PROARTE 2026

Projeto organizado para edição no Visual Studio Code.

## Estrutura

```text
workshop-proarte-2026/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── img/
    └── icons/
```

## Imagens necessárias

Coloque as imagens usadas pela página dentro da pasta `assets/` com estes nomes:

- `logo-proarte.png`
- `logo-dnit.png`
- `hero-ponte.jpeg`
- `ponte-oae.jpeg`
- `ponte-bonitinha.png`

## Como abrir no VSCode

1. Descompacte esta pasta.
2. Abra o Visual Studio Code.
3. Vá em **File > Open Folder...** ou **Arquivo > Abrir Pasta...**.
4. Selecione a pasta `workshop-proarte-2026`.
5. Abra o arquivo `index.html`.
6. Para visualizar, clique com o botão direito no `index.html` e use **Open with Live Server** se tiver a extensão instalada. Sem a extensão, dê dois cliques no arquivo no Explorador de Arquivos.
